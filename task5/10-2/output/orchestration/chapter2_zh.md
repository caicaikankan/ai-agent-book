

# 第二章：Transformer与注意力机制

现代语言模型均基于**Transformer**架构构建。其核心思想是**注意力机制**：模型不再严格按从左到右的顺序处理序列，而是允许每个词元关注其他所有词元并决定哪些词元更重要。这正是Transformer能够将代词与前面多个词元的名词建立关联的原因。

注意力机制作用于每个词元的**嵌入向量**。对于每个词元，模型会计算三个向量——查询向量、键向量和值向量，并通过它们来衡量每个词元应关注其他词元的程度。

```python
def attention(query, key, value):
    scores = query @ key.T          # 词元间的相似度
    weights = softmax(scores)       # 注意力权重
    return weights @ value          # 加权嵌入向量
```

由于注意力机制需要将每个词元与其他所有词元进行比较，其计算成本会随着提示词长度的增加而迅速增长。这是导致时延问题的根源，也是下一章我们将重点解决的课题。然而，正是这种注意力机制赋予了Transformer强大的能力：在推理过程中，它能让模型灵活地在整个提示词范围内路由信息，而非受限于固定流程。
