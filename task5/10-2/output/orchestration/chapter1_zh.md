

# 第1章：大语言模型推理的基础

大语言模型在能够进行任何推理之前，会先将文本转化为数字。每一段文本首先会被拆分为一个**词元**（token），这是模型处理的最小单元。随后，每个词元会被映射为一个**嵌入向量**（embedding），这是一种在高维空间中捕捉词元含义的密集向量。

当用户发送请求时，他们输入的文本被称为**提示词**（prompt）。通过该提示词运行模型以生成回答的过程称为**推理**（inference）。用户从发送提示词到收到首个响应之间的时间间隔就是他们直接感受到的**时延**（latency）。

一个最简的推理调用示例如下：

```python
def generate(prompt: str, model) -> str:
    tokens = model.tokenize(prompt)      # 将提示词拆分为词元
    embeddings = model.embed(tokens)     # 将每个词元映射为嵌入向量
    output = model.forward(embeddings)   # 执行推理
    return model.detokenize(output)
```

两个关键指标主导着用户体验。首先是提示词中的词元数量，因为更长的提示词需要更多的计算资源。其次是首个词元的时延，因为缓慢的首个词元会让整个系统显得迟滞。贯穿本书始终，我们反复探讨这些概念：词元、嵌入向量、提示词、推理和时延。现在准确理解这些术语的定义，将有助于避免后续的混淆。
