

# 第4章：微调与部署

通用模型通常无法直接满足特定产品的需要。通常的解决方法是**微调**：在更小、更具任务针对性的数据集上继续训练模型，使其适应您的领域，同时保留其通用能力。

**微调**会改变模型将**提示词**转换为答案的方式，但不会改变基础流程：文本被转换为**词元**，每个**词元**生成**嵌入向量**，并通过**推理**得出结果。发生变化的是模型所学习到的权重。

```python
def fine_tune(model, dataset):
    for prompt, target in dataset:
        loss = model.loss(prompt, target)   # 比较输出与目标
        model.update(loss)                  # 调整权重
    return model
```

微调之后便是**部署**：将模型封装在API背后，使真实用户能够发送提示词并获取答案。此时，之前提到的诸多问题将再次凸显。时延必须保持低位，吞吐量必须保持高位，而前一章提到的键值缓存 [待审] 和批处理 [待审] 技术则承担了主要工作。

至此，整个流程——词元、嵌入向量、提示词、推理、时延、微调与部署——已全部完成。曾经仅是研究产物的模型，如今已演变为人们实际可用的服务。
