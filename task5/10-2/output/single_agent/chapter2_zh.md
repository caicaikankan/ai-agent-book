

# 第2章：Transformer与注意力机制

现代语言模型均基于**Transformer**架构构建。其核心思想是**注意力机制**（attention）：与传统的严格从左到右逐字处理不同，模型允许每个标记与其他所有标记进行交互，并决定哪些标记更重要。这正是Transformer能够将代词与前面多个标记位置的名词建立联系的原因。

注意力机制作用于每个标记的**嵌入向量**（embedding）。对于每个标记，模型会计算三个向量——查询向量（query）、键向量（key）和值向量（value）——并利用它们来确定每个标记应关注其他标记的程度。

```python
def attention(query, key, value):
    scores = query @ key.T          # 标记间的相似度计算
    weights = softmax(scores)       # 注意力权重
    return weights @ value          # 加权后的嵌入向量
```

由于注意力机制需要将每个标记与其他所有标记进行比较，其计算成本会随着提示长度的增加而迅速增长。这是下一章我们将重点解决的延迟问题的根本原因。然而，正是这种注意力机制赋予了Transformer强大的能力：在推理过程中，它能让模型灵活地在整个提示序列中路由信息，而非受限于固定的处理流程。
