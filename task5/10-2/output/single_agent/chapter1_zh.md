

# 第1章：LLM推理基础

大型语言模型在能够对任何内容进行推理之前，会将文本转换为数字。每一段文本首先会被拆分为**标记**（token），这是模型处理的最小单元。随后，每个标记会被映射为一个**嵌入向量**（embedding），即一个密集的向量，用于在高维空间中捕捉其语义。

当用户发送请求时，他们输入的文本被称为**提示**（prompt）。将模型应用于该提示以生成答案的过程称为**推理**（inference）。用户从发送提示到收到首个响应之间的时延被称为**延迟**（latency），这是用户直接感知到的性能指标。

一个最简的推理调用示例如下：

```python
def generate(prompt: str, model) -> str:
    tokens = model.tokenize(prompt)      # 将提示拆分为标记
    embeddings = model.embed(tokens)     # 将每个标记映射为嵌入向量
    output = model.forward(embeddings)   # 执行推理
    return model.detokenize(output)
```

用户体验主要受两个数值影响。首先是提示中的标记数量，因为更长的提示需要更多的计算资源。其次是首个标记的延迟，因为首标记响应缓慢会让整个系统显得卡顿。贯穿本书始终，我们反复探讨这些核心概念：标记、嵌入向量、提示、推理和延迟。现在准确理解这些定义将有助于避免后续的混淆。
