

# 第4章：微调与部署

通用模型很少能直接适配特定产品。通常的解决方案是**微调**（fine-tuning）：在更小、更具任务针对性的数据集上继续训练模型，使其在保持通用能力的同时适应特定领域。

微调会改变模型将**提示**转化为答案的方式，但不会改变基础流程：文本被转换为**标记**，每个标记被映射为**嵌入向量**，并通过**推理**生成结果。真正发生变化的是模型所学习到的参数权重。

```python
def fine_tune(model, dataset):
    for prompt, target in dataset:
        loss = model.loss(prompt, target)   # 将输出与目标进行对比
        model.update(loss)                  # 调整权重
    return model
```

微调之后是**部署**（deployment）：将模型封装为API服务，使真实用户能够发送提示并获取答案。此时之前讨论的问题会再次凸显：延迟必须保持低位，吞吐量必须维持高位，而上一章提到的键值缓存和批量处理技术则承担了主要的性能优化工作。

从**标记**、**嵌入向量**、**提示**、**推理**、**延迟**，到**微调**和**部署**，整个流程至此完整闭环。一个曾仅作为研究工具的模型，现在已转变为人们实际可用的服务。
