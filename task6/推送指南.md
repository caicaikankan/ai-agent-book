## 三、新电脑上的操作步骤（交给 Trae 执行）

### 步骤 1：检查环境

```powershell
git --version
git config --global user.name    # 原电脑为 xgy；新电脑若为空需配置
git config --global user.email   # 原电脑为 hnlyxgy@163.com
```

若 name/email 为空：

```powershell
git config --global user.name "xgy"
git config --global user.email "hnlyxgy@163.com"
```

### 步骤 2：验证仓库完整性

在项目根目录执行：

```powershell
git log --oneline      # 应看到 9 个提交（Task 0～Task 6 + chore + 交接）
git remote -v          # 应看到 origin → github.com/caicaikankan/ai-agent-book.git
git status             # 应为 working tree clean
```

### 步骤 3：挂好 VPN / 代理，确认能打开 github.com

如 Git 需要单独走代理（把端口换成代理软件实际端口，常见 7890）：

```powershell
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890
# 用完或不需要时取消：
# git config --global --unset http.proxy
# git config --global --unset https.proxy
```

### 步骤 4：创建 GitHub 空仓库

浏览器打开 https://github.com/new （已登录账号 `caicaikankan`）：

- Repository name：`ai-agent-book`
- 选 **Public**
- 下面三个选项（README / .gitignore / license）**全部不勾**
- 点 **Create repository**

### 步骤 5：推送

```powershell
git push -u origin main
```

- 若弹出登录窗口，浏览器授权即可；若要求命令行输入凭据，需用 **Personal Access Token**（GitHub → Settings → Developer settings → Personal access tokens 生成，勾选 repo 权限），密码处粘贴 token
- 网络失败不要反复硬刷，等待后重试

### 步骤 6：开启 GitHub Pages 发布知识地图

1. 推送成功后，仓库页面 → **Settings** → **Pages**
2. Source 选 **Deploy from a branch**
3. Branch 选 `main`，文件夹选 `/ (root)`，保存
4. 等待 1～2 分钟，页面顶部出现网址，形如：
   `https://caicaikankan.github.io/ai-agent-book/`
5. 知识地图的直接链接为：
   `https://caicaikankan.github.io/ai-agent-book/task6/knowledge-map/knowledge_map.html`

注意：知识地图 HTML 为自包含文件，直接发布即可，不依赖同目录的 experiments.json。
